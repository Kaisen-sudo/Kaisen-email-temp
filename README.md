# ⚡ KAISEN EMAIL TEMP

**KAISEN EMAIL TEMP** est une application web de messagerie temporaire ultra-rapide avec une esthétique Cyberpunk. Protégez votre vie privée en générant des adresses e-mails jetables instantanément.

## ✨ Fonctionnalités
- 📧 **Génération instantanée** : Créez une nouvelle adresse en un clic.
- 📥 **Inbox en temps réel** : Les messages s'affichent automatiquement sans rafraîchir la page.
- 🔔 **Notifications sonores** : Soyez averti dès qu'un e-mail arrive.
- 🎨 **Design Cyberpunk** : Interface sombre avec effets néon (Violet & Cyan) et grille 3D animée.
- 📱 **Responsive** : Parfaitement optimisé pour mobile et bureau.
- 🚀 **Déploiement facile** : Compatible avec Vercel, Netlify et GitHub Pages.
